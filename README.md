# 📝 Basic To-Do List App

A clean, responsive To-Do List application built with vanilla HTML5, CSS3, and JavaScript. Tasks persist across browser sessions using LocalStorage.

🔗 **[Live Demo](https://understooduseyourusernamehere.github.io/To-Do-List/)**

---

## Features

- **Add & Edit Tasks:** Add new goals by clicking the add button or pressing `Enter`. Click any existing task name to edit it directly.
- **Completion Toggle:** Mark tasks complete with custom checkmarks and strike-through styling.
- **Local Storage Persistence:** Keeps your task list intact even after closing or refreshing the browser.
- **Goal Counter:** Real-time tracking of total tasks.
- **Bulk Clear:** One-click "Delete All" action.

---

## Built With

- **HTML5:** Semantic document structure
- **CSS3:** Custom properties (CSS variables), Flexbox, CSS pseudo-elements, and transitions
- **JavaScript (ES6):** DOM manipulation, Event listeners, and `localStorage` API
